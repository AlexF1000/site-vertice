# Vértice Social Mídia & Performance

Site institucional e blog da agência Vértice Social Mídia & Performance.

## 🚀 Tecnologias
- HTML5 Semântico
- Tailwind CSS v3
- JavaScript Vanilla
- Otimização para SEO e Core Web Vitals

## 📁 Estrutura de Pastas
- `dist/`: Arquivos prontos para produção (HTMLs, assets, blog).
- `src/`: Arquivos fonte de estilos (`input.css`).
- `imagens/`: Recursos de imagens do projeto.
